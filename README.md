# 🛡️ Network Attack Detection System

## 🇬🇧 English

# Bachelor Thesis Project - Varna Free University

This project was developed as part of a Bachelor's thesis at **Varna Free University "Chernorizets Hrabar"**.

The goal of the project is to design and implement a modern **AI-powered Intrusion Detection System (IDS)** and **Security Operations Center (SOC) dashboard** for real-time network traffic analysis, attack detection, threat scoring, and cybersecurity monitoring.

---

# 🔐 Project Overview

The platform combines:

- Machine Learning
- Real-time network monitoring
- Packet inspection
- Threat analytics
- Alert management
- Security visualization
- SOC-style dashboards

into a single integrated cybersecurity platform.

The system analyzes network traffic and detects suspicious or malicious activity using machine learning models trained on the **CIC-IDS2017 dataset**.

---
